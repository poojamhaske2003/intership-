# Cyber Security Risk Assessment

## Objective
Perform a basic cyber security risk assessment for a fictional organization and identify assets, threats, vulnerabilities, risks, and security controls.

## Scenario
Organization: ABC Online Retail Store

## Assets Identified
- Customer Database
- Web Application
- Employee Systems
- Payment Processing System
- Company Network

## Threats
- Phishing Attacks
- Malware Infections
- Data Breaches
- Ransomware
- Insider Threats

## Vulnerabilities
- Weak Passwords
- Unpatched Software
- Lack of MFA
- Poor Access Control
- Employee Security Awareness Gaps

## Risk Assessment

| Asset | Threat | Vulnerability | Risk Level |
|---------|---------|--------------|------------|
| Customer Database | Data Breach | Weak Passwords | High |
| Web Application | SQL Injection | Input Validation Issues | High |
| Employee Systems | Malware | Unpatched Software | Medium |
| Payment System | Credential Theft | No MFA | High |

## Recommended Controls
- Multi-Factor Authentication (MFA)
- Regular Security Updates
- Employee Security Training
- Strong Password Policy
- Data Encryption
- Access Control Mechanisms
- Regular Vulnerability Assessments

## Conclusion
Implementing appropriate security controls significantly reduces cyber risks and improves organizational security posture.
